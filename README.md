## 📘 Exercícios de Programação – 1º Ano
UCE – Programação de Computadores I & II

Exercícios realizados nas aulas do professor Daniel, utilizando JavaScript.

Este repositório reúne todos os exercícios desenvolvidos durante o primeiro ano do curso, organizados por bimestre e por tema.
O objetivo é registrar a evolução no aprendizado de lógica de programação e práticas iniciais de desenvolvimento.

## 📚 Conteúdo do Repositório
1️⃣ Programação de Computadores I (1º Bimestre)

Introdução aos fundamentos da programação:

Variáveis e tipos de dados

Entrada e saída

Operações matemáticas

Estruturas condicionais (if/else)

Estruturas de repetição (for / while)

Exercícios práticos básicos

## 2️⃣ Programação de Computadores II (2º Bimestre)

Conceitos intermediários de programação:

Funções

Vetores e matrizes

Manipulação de strings

Repetições aninhadas

Algoritmos com maior complexidade

Exercícios completos em arquivos separados

## 🧠 Tecnologias Utilizadas

JavaScript (navegador)

Editor de código de sua preferência
(VS Code recomendado)

## 🎯 Objetivo

O repositório serve para:

Acompanhar sua evolução no aprendizado

Guardar suas resoluções para estudos futuros

Usar como portfólio no GitHub

Comparar soluções com versões otimizadas (se quiser, posso gerar também)
